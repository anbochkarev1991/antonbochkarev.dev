# antonbochkarev.dev

Personal freelance portfolio site. Single-page static HTML for headless commerce engineering positioning.

## Stack

- Static HTML + CSS (no JavaScript, no build step)
- Inter font via Google Fonts
- GitHub Pages hosting
- JSON-LD structured data (Person / ProfilePage)
- Responsive, dark mode via `prefers-color-scheme`

## Local development

Open `index.html` in a browser. No server needed.

## Deployment

Deployed automatically via GitHub Pages on push to `main`. Custom domain configured via `CNAME` file.

## SEO

- `sitemap.xml` for search engine crawlers
- `robots.txt` allowing all user agents
- Open Graph and Twitter Card meta tags
- JSON-LD structured data for rich results
